**Status**: Accepted baseline inventory
**Date**: 2026-08-27
**Scope**: Section 1, Task 1.1

migration. It is an inventory, not a claim that every listed resource has
already been migrated.

## API and resource-name inventory

The current Manager API is implemented in `backend/manager/api/v1/`. The
service/resource families named by the proposal are mapped as follows:

| Current service family | Current implementation | Target resource scope |
| --- | --- | --- |
| Organization/workspace/membership | `organization_service.go` | `organizations/{organization}` and workspaces |
| Users/principals | `user_service.go` | organization membership context |
| Agents and runtime | `agent.go`, `agent_config.go`, `agent_connection.go` | `organizations/{organization}/workspaces/{workspace}/agents/{agent}` |
| Machines | `machine.go`, `machine_connection.go` | `organizations/{organization}/machines/{machine}` |
| Channels and conversations | `channel.go`, `channel_message.go`, `command_message.go` | organization/workspace conversation |
| Commands/tasks | `command.go`, `task.go` | organization/workspace work resource |
| IAM | `iam.go`, `iam_service.go`, `authz_helper.go` | tenant-first authorization |
| MCP | `mcp_server_service.go`, `mcp_gateway_service.go` | organization-scoped server |
| API providers | `api_provider_service.go`, `agent_api_provider.go` | organization-scoped provider |
| A2A work | `backend/a2a/` | `organizations/{organization}/a2a/work/{work}` |
| Audit/notifications/reminders | `audit_log_service.go`, `notification_service.go`, `reminder.go` | organization-scoped where persisted |

The target hierarchical forms are additive names for public contracts:

```text
organizations/{org}/workspaces/{workspace}/agents/{agent}
organizations/{org}/workspaces/{workspace}/conversations/{conversation}
organizations/{org}/workspaces/{workspace}/tasks/{task}
organizations/{org}/machines/{machine}
organizations/{org}/connectors/{connector}/installations/{installation}
organizations/{org}/approvals/{approval}
organizations/{org}/a2a/work/{work}
```

Existing flat IDs remain implementation identifiers during the compatibility
window. Resource resolution must establish organization scope before querying
an ID, and must return the same denial behavior for an unknown ID and an ID
owned by another organization.

## Process-local realtime and correctness paths

The following paths were verified by source inspection on 2026-08-27:

| Path | Current mechanism | Failure on another Manager replica |
| --- | --- | --- |
| `backend/manager/component/roomhub/` | in-process subscriber map plus PostgreSQL wake-up | live subscribers need durable history/reconciliation |
| `backend/manager/api/v1/command_message.go` | long-poll request-local wait channels | a watcher connected to another replica misses the local fast path |
| `backend/manager/component/dispatcher/` | in-memory command/event watcher maps | watcher state is lost on process restart |
| `backend/manager/api/auth/auth.go` | `authContextCache sync.Map` | cache is not shared between replicas |
| `backend/manager/api/v1/machine_connection.go` | active connection/session state | dispatch cannot rely on local connection ownership |
| `backend/manager/component/state/` | local nonce key/replay fallback, with durable hook | fallback is process-local when no store is wired |

These are fast paths, not authoritative durable state. The durable replacements
already present in the repository include PostgreSQL outbox/event tables,
message projections, command event replay and shared nonce replay. The
remaining migration work must preserve the durable source of truth while
retaining local wake-up optimizations.

## Migration inventory and traceability

Incremental migrations are numbered `0001` through `0041` in the 1.1 stream;
`LATEST.sql` is the fresh-install snapshot. The relevant groups are:

| Migration range | Inventory responsibility |
| --- | --- |
| `0001`–`0025` | original single-workspace principals, agents, machines, conversations, commands and provider/MCP tables |
| `0026`–`0027` | durable A2A work and Machine assignment state |
| `0028` | organizations, workspaces and memberships plus default-tenant backfill |
| `0029`–`0033` | outbox, connector inbox, reconciliation and shared nonce replay |
| `0034`–`0039` | Message Plane identity, cursors, projections, reconciliation and execution events |
| `0040`–`0041` | Organization approvals and Web Widget configuration |

The inventory covers every database table and service/resource family named in
`proposal.md`. Planned capabilities that have no table or service yet are
explicitly represented by the target rows above (connectors, usage and billing
are future work); they are not reported as implemented.

## Decision

Use `LATEST.sql`, the numbered migration stream, and the checked-in service
files as the baseline sources for future architecture decisions. Task 1.1 is
verified by the complete table extraction, service mapping, process-local path
audit, and migration traceability recorded here. No production behavior is
changed by this inventory.
